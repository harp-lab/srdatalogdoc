Detailed Description

template<tmp::CTuple MIROps, typename CanonicalIndexSpecs>
struct SRDatalog::ReplaceDestinationRelationsInTuple< MIROps, CanonicalIndexSpecs >

Transforms all DestinationRelation operations in a tuple to use canonical indices.

Applies ReplaceDestinationRelationWithCanonicalIndex to each element in the tuple, replacing DestinationRelation operations with canonical indices.
