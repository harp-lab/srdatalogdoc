Detailed Description

template<tmp::CTuple RuleList>
struct SRDatalog::ComputeIndicesForRules< RuleList >

Join plan for Worst-Case Optimal Join (WCOJ) algorithms.

A join plan specifies the order in which logical variables should be bound during join execution. The naive join plan uses the appearance order of variables in the rule body. More sophisticated plans can optimize join order based on selectivity and data distribution.

Computes indexes for multiple rules.

Processes a list of rules and collects all required indexes, flattening the result into a single tuple.
