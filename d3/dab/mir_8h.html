Detailed Description

Mid-level Intermediate Representation (MIR) definitions and compilation.

This file contains all MIR-related definitions including:

  • MIR AST structures (ColumnSource, ColumnJoin, DestinationRelation)
  • Index specifications (IndexSpecT)
  • Rule-to-MIR compilation functions (CompileRuleToMIR, etc.)

MIR is generated from the high-level AST during compilation and is closer to the actual execution model, enabling column-oriented join operations.
