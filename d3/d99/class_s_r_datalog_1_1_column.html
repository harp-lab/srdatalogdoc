Detailed Description

template<class T>
class SRDatalog::Column< T >

Thin, PMR-aware contiguous column wrapper.

Column<T> mirrors the interface of a std::vector<T> but stores data in a polymorphic memory-resource (PMR) container by default. The implementation is header-only with out-of-class definitions placed in column.ipp.

TThe element type stored in the column (must satisfy ColumnElement)
