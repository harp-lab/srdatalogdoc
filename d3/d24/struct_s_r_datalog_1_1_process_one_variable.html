Detailed Description

template<tmp::CTuple AllJoinPlan, tmp::CTuple AllBodyClauses, tmp::CTuple Indices>
struct SRDatalog::ProcessOneVariable< AllJoinPlan, AllBodyClauses, Indices >

Fold operation functor for processing one variable from the join plan.

Used with mp::mp_fold_q to process each variable in the join plan sequentially, accumulating MIR operations. This implements the core of the rule body compilation algorithm.

Template Parameters
AllJoinPlanThe complete join plan (all variables)
AllBodyClausesAll clauses in the rule body
IndicesThe computed IndexSpecs (for reference)
