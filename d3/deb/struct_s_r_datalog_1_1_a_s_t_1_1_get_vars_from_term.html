Detailed Description

template<CTerm T>
struct SRDatalog::AST::GetVarsFromTerm< T >

Template metaprogramming trait to extract variables from a term.

Given a term (Var, Const, or CppExpr), returns a std::tuple of the variables that term depends on. Used for dependency analysis during compilation.

Template Parameters
TThe term type (must satisfy CTerm concept)
Note
  • For Var: returns std::tuple<Var>
  • For Const: returns std::tuple<> (constants have no dependencies)
  • For CppExpr: returns the CapturedVars tuple
