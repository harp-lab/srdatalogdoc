Detailed Description

template<CDatabase DBType, template< typename > typename RelationMapper = SchemaToRelation>
struct SRDatalog::AST::SemiNaiveDatabase< DBType, RelationMapper >

Runtime database structure for semi-naive evaluation.

Represents a database with three versions of each relation:

  • full: The complete relation (all facts derived so far)
  • delta: Facts derived in the previous iteration
  • newt: Facts derived in the current iteration

This structure enables semi-naive evaluation, an optimization for recursive rules that avoids redundant computation by only processing new facts.
