Detailed Description

template<typename I = uint32_t>
struct SRDatalog::GPU::SortContext< I >

Context structure to hold reusable buffers for sorting operations.

This context is slightly simpler than Highway's SortContext because we don't need to manually push the index into the context, sort_by_key works well on GPU.

The context maintains device-side buffers that are reused across multiple sorting operations to avoid repeated allocations.
