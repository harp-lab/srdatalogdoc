Detailed Description

Thin, PMR-aware contiguous column wrapper and encoding/decoding system.

This file provides the Column class for storing attribute data in a column-oriented format, along with encoding/decoding utilities for converting values to/from size_t for efficient indexing.

Note
C++20/23 Features Used: This file uses C++20 concepts extensively for type constraints (Encodable, Decodable, Codec, ColumnElement, ColumnElementTuple), requires clauses for template constraints, std::bit_cast for type-punning, if constexpr for compile-time conditionals, fold expressions for tuple element checking, and C++17 if statement with initialization.
