Detailed Description

Test to expose deduplication bugs in GPU SG fixpoint execution.

This test is designed to catch the issue where results are 2x the correct value, indicating deduplication is not working correctly.

BOOST_AUTO_TEST_CASE ( test_sg_deduplication_exact_small  )

Test with known exact result - will catch 2x bug.

This test uses a small graph where we can manually compute the exact expected result. If deduplication fails and we get 2x the correct count, this test will fail.

Graph: 1->2, 1->3, 2->3 Base rule: sg(x,y) :- arc(p,x), arc(p,y), x != y Source 1: arcs to 2,3 -> sg(2,3) = 1 tuple Source 2: arcs to 3 -> no result (need 2+ arcs) Source 3: no arcs -> no result Total base: 1 unique tuple

Fixpoint iteration 0: sg(x,y) :- sg.delta(p,q), arc(p,x), arc(q,y) sg.delta redirects to sg.full which has sg(2,3) Join: sg(2,3) + arc(2,?) + arc(3,?)

  • arc(2,3) exists, but no arc(3,?) -> no new tuples Total after iter 0: 1 unique tuple (same as base)

Expected final result: 1 unique tuple If we get 2, deduplication is broken (2x bug)
