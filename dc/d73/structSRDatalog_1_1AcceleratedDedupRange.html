Detailed Description

template<typename T, std::size_t BlockSize = 64>
struct SRDatalog::AcceleratedDedupRange< T, BlockSize >

A range view that provides accelerated iteration over deduplicated values.

Similar to DedupRange but uses AcceleratedArrayIterator which leverages Eytzinger index for faster seeks in large sorted arrays.

Template Parameters
TThe value type
BlockSizeThe block size for Eytzinger indexing (default: 64)
