Detailed Description

template<Semiring SR, typename ValueTypeParam = uint32_t>
struct SRDatalog::GPU::NodeView< SR, ValueTypeParam >

Immutable view of the index structure (pointers only).

Contains all the invariant pointers needed to traverse the index. Passed to kernel as a single structure, shared by all threads.
