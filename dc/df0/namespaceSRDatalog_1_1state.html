auto& SRDatalog::state::get_iterator_ref ( IteratorTuple &  iterators)

Gets a mutable reference to an iterator from IteratorTuple using IteratorPosMap.

Looks up the iterator position from IteratorPosMap at compile-time, then returns a mutable reference to the iterator at that position in IteratorTuple. This allows the caller to modify the iterator in-place (e.g., apply prefixes).

Template Parameters

IteratorTupleRuntime tuple of iterators
IndexSpecTThe IndexSpecT type to look up
Parameters
iteratorsThe runtime iterator tuple (passed by reference)
Returns
Mutable reference to the iterator at the position specified by IteratorPosMap

Get value for a single term (Var, Const, or CppExpr) from tuple-based state.

Handles different term types:

  • Const: returns compile-time constant value
  • CppExpr: evaluates expression with captured variables (not yet fully supported)

Set a value at a specific position in the tuple-based state.

Sets the value for a variable at its compile-time determined position. The state tuple must be pre-allocated with the correct size based on the join plan. All variable positions are known at compile time, so the tuple type is fixed.

Updates an iterator in IteratorTuple by replacing it with itself prefixed with a value.

Looks up the iterator mapped to the given Index and replaces it with itself prefixed with the provided value. This is useful for updating iterators when variable bindings change. Handles both single values and tuples of values.
