Detailed Description

PMR memory resource that uses Highway's aligned allocation functions.

This memory resource provides 64-byte aligned allocations compatible with SIMD operations. It uses Highway's AllocateAlignedBytes and FreeAlignedBytes functions, which are target-independent and work across all SIMD targets.

Note
This is particularly useful for Highway VQSort and other SIMD operations that require aligned memory.
