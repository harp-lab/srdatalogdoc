Detailed Description

template<tmp::CTuple BodyClauses, tmp::CTuple GlobalJoinPlan>
struct SRDatalog::MapClausesToSpecs_Impl< BodyClauses, GlobalJoinPlan >

Maps all body clauses to their required IndexSpecs.

Filters body clauses to only normal clauses (excluding LetClauses) and computes the IndexSpec for each. This produces the complete set of indexes needed to execute the rule body efficiently.

Template Parameters
BodyClausesA std::tuple of clause types (normal and let)
GlobalJoinPlanA std::tuple of Var types specifying the join order
