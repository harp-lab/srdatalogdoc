Detailed Description

template<CVar VarToFind, typename StateMap>
struct SRDatalog::detail::GetValueFromState< VarToFind, StateMap >

Boost.Hana map-based state management for variable bindings.

The state is now represented as a hana::map where:

  • Keys are compile-time variable types wrapped in hana::type_c<Var>
  • Values are runtime values bound to those variables

Benefits over tuple-based approach:

  • O(1) compile-time lookup instead of O(n) linear search
  • More semantically clear: explicit key-value mapping
  • Better error messages when variable not found
  • Type-safe: keys are types, preventing runtime key errors
  • Easier to extend with additional operations (contains, keys, values, etc.)
Template Parameters
VarToFindThe compile-time Var type to search for
StateMapThe runtime state as hana::map (hana::map<hana::pair<hana::type<Var>, Value>...>)
