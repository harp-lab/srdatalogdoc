Detailed Description

template<Semiring SR, ColumnElement... AttrTs>
class SRDatalog::Relation< SR, AttrTs >

Column-oriented Relation class.

This class implements a column-oriented relation storage system optimized for Datalog evaluation. Key features:

  • Column-oriented storage (SoA): Each attribute type is stored in a separate column, providing better cache locality for analytical workloads
  • Semiring annotations: One annotation column stores semiring values (SR::value_type) for each row, enabling provenance tracking and aggregation
  • Interned columns: Encoded versions of attributes (as size_t) for efficient indexing and comparison
  • HashTrie indexing: Multi-level trie indexes for efficient prefix lookups
  • Lazy index building: Indexes are built on-demand when first accessed
Template Parameters
SRThe semiring type used for the annotation (must satisfy Semiring concept)
AttrTsThe types of the attributes (must satisfy ColumnElement concept)

Relation Structure

A Relation consists of:

  • cols_: Tuple of Column<T> objects, one per attribute
  • ann_: Vector of annotation values (semiring values)
  • interned_cols_: Array of encoded columns (Vector<size_t>)
  • indexes_: Map of IndexSpec -> HashTrieIndex for efficient lookups

Indexing Usage

Indexes are specified using IndexSpec, which defines which columns form the index key:

// Create index on columns 0 and 1
IndexSpec spec;
spec.cols = {0, 1};
const auto& idx = rel.ensure_index(spec);
// Query using encoded prefix
auto prefix = Prefix<int, int>{5, 10};
auto node = rel.indexed_range_query(spec, prefix.encoded());
for (auto row_id : node.rows()) {
// Process matching rows
}

inline

Clone this relation into another relation.

Performs a deep copy of all relation data into the target relation. This includes:

  • All attribute columns
  • All annotation values
  • All interned columns

Note: Indexes are NOT cloned or rebuilt. The target relation's indexes will be marked as dirty and will need to be rebuilt if needed.

Parameters
otherThe target relation to clone into (will be cleared first)

template<Semiring SR, ColumnElement... AttrTs>
void SRDatalog::Relation< SR, AttrTs >::concat ( const Relation< SR, AttrTs... > & other)
inline

Concatenate another relation to this relation.

Appends all rows from the other relation to this relation. This includes:

  • All attribute columns
  • All annotation values
  • All interned columns

The operation reserves capacity for efficiency and preserves the order of rows. Indexes are not automatically rebuilt after concatenation.

Parameters
otherThe relation to concatenate from (source remains unchanged)
