Detailed Description

template<typename HandleType, std::size_t NumHandles>
struct SRDatalog::GPU::state::HandleStore< HandleType, NumHandles >

HandleStore - Stores iterator handles in a linear array.

accessing handles is done by index (0 to NumHandles-1).
