15  * @brief In-place merge of two sorted Structure-of-Arrays (SoA) data structures.
16  *
17  * @details This function performs an optimal in-place merge of two sorted SoA structures.
18  * The merge strategy:
19  * 1. Resize destination vectors to accommodate merged result
20  * 2. Move existing data from [0, old_size-1] to [other_size, total_size-1]
21  * 3. Merge forward: read from moved data [other_size, ...] and other [0, ...],
22  * write to [0, ...]
23  * This avoids overwriting unread data and is optimal for in-place merge.
24  *
25  * @tparam ValueType The value type stored in columns
26  * @tparam RowIdType The row ID type
27  * @tparam ColumnContainer Container type for columns (must support .data(), .resize(), .size())
28  * @tparam PostingContainer Container type for postings (must support .data(), .resize())
29  *
30  * @param this_cols Vector of column containers for "this" (destination) data
31  * @param this_postings Postings container for "this" data
32  * @param other_cols Vector of column containers for "other" (source) data
33  * @param other_postings Postings container for "other" data
34  * @param old_size Current size of "this" data (before merge)
35  * @param other_size Size of "other" data
36  * @param row_id_offset Offset to add to row IDs from "other" when merging
37  *
38  * @return The final merged size (total_size = old_size + other_size)
39  */
