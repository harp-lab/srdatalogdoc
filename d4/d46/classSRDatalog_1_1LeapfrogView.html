Detailed Description

template<typename... Iterators>
class SRDatalog::LeapfrogView< Iterators >

A C++20 View implementing Leapfrog Triejoin (Galloping Intersection).

Unlike std::views::filter, this view utilizes the .seek() method on the underlying iterators to skip ranges of non-matching values efficiently. This implements the "leapfrog" algorithm where iterators take turns being the leader, and other iterators "seek" to catch up.

Template Parameters
IteratorsVariadic pack of iterator types that support:
  • Dereference operator (*)
  • Increment operator (++)
  • Equality comparison (==)
  • seek(value) method for efficient skipping
