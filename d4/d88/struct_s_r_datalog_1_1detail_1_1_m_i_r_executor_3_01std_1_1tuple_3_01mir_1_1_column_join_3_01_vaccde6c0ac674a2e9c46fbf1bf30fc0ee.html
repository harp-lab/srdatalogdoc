template<CVar VarToBind, tmp::CTuple Sources, typename... TailOps, typename StateMap>
struct SRDatalog::detail::MIRExecutor< std::tuple< mir::ColumnJoin< VarToBind, Sources >, TailOps... >, StateMap >

Specialization for ColumnJoin: executes a multi-way join operation.

This specialization handles the ColumnJoin MIR operation, which binds a variable by intersecting multiple column sources. The execution proceeds as:

  1. Generate iterators for all column sources
  2. Compute hash intersection of all iterators
  3. For each value in the intersection, bind the variable using hana::insert and recurse

This implements Worst-Case Optimal Join (WCOJ) semantics. Version is extracted from the first ColumnSource in Sources.

Template Parameters
VarToBindThe variable to bind through this join
SourcesThe tuple of ColumnSource operations to intersect
TailOpsThe remaining MIR operations to execute after this join
StateMapThe current runtime state as hana::map (variable bindings)
