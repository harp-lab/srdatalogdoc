Detailed Description

template<typename PosMap, std::size_t Pos>
struct SRDatalog::state::FindTypeAtPos< PosMap, Pos >

Extracts a type that maps to a specific position in a position map.

Finds the type that maps to the given position by iterating through all keys in the map and checking their position values. Works with any compile-time hana::map that maps types to positions (e.g., VarPosMap, IteratorPosMap).

Template Parameters
PosMapCompile-time hana::map mapping types to positions
PosThe position to find
