Detailed Description

Configuration for RMM pool memory resource.

Pool sizes can be configured via environment variables:

  • SRDATALOG_RMM_POOL_INITIAL_SIZE: Initial pool size in bytes (default: 1GB)
  • SRDATALOG_RMM_POOL_MAX_SIZE: Maximum pool size in bytes (default: unlimited) Set to 0 or use environment variable to specify a limit, otherwise unlimited
    Note
    If environment variables are not set, uses default values (unlimited max size)
