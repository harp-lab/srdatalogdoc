Detailed Description

template<CQuery Q>
struct SRDatalog::ExecuteQuery< Q >

Functor for executing queries (non-iterative rule sets or fixpoint).

This is the main entry point for executing queries. It dispatches to the appropriate execution functor based on the query type:

  • CFixpoint: uses ExecuteRulesForFixpoint functor
  • CNonIterativeRuleSets: uses ExecuteRulesForNonIterativeRuleSets functor

Exposes compile-time types for debugging and clarity by providing access to the underlying executor types.

Template Parameters
QA CQuery type (either CFixpoint or CNonIterativeRuleSets)
