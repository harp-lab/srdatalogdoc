Detailed Description

template<typename... IndexSpecs>
struct SRDatalog::mir::ComputePipelineIteratorPosMap< IndexSpecs >

Computes IteratorPosMap from MIR pipeline operations.

Extracts all IndexSpecT types from MIR operations and computes a position map. This is a convenience helper that combines ExtractIndexSpecsFromMIR and ComputeIndexSpecToIteratorPosMap.
