Detailed Description

template<typename... IndexSpecs>
struct SRDatalog::mir::ComputePipelineIteratorPosMap< IndexSpecs >

Computes the IndexSpecT-to-iterator-position map for a Pipeline.

Extracts all IndexSpecT from the pipeline's MIR operations, makes them unique, and creates a map from each IndexSpecT type to its position in the iterator tuple.
