Detailed Description

Concept that checks if StateMap is a valid compile-time state map for a given Var.

This concept verifies that StateMap is a Boost.Hana map-like structure that can store and retrieve runtime values associated with compile-time Var types.

The concept checks:

  • StateMap supports indexing with hana::type_c<Var> keys
  • StateMap supports membership checking with hana::contains
  • StateMap supports key iteration via hana::keys
Template Parameters
StateMapThe type to check (should be hana::map or compatible)
VarThe variable type to test with (must satisfy CVar)
