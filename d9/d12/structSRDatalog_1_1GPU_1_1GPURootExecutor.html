inlinestatic

Kernel to materialize the resulting tuples.

Performs the actual join, duplicate check, and writes the results to output_data. Uses thread_offsets computed from an exclusive scan of the counts.

Parameters
root_handlesHandles to the root relations
full_handlesHandles to full destination relations
num_root_keysNumber of keys in the first root relation
thread_offsetsScanned offsets for where each thread should write
output_dataBuffer for output tuple data
output_provBuffer for output provenance
output_strideStride of the output buffer columns
