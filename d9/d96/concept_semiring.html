Detailed Description

Concept defining the interface for semiring types.

A semiring must provide a value_type, identity elements (zero, one), and operations (add, mul). This concept ensures type safety and enables generic programming over different semiring implementations.

Note
C++20 feature: Uses C++20 concepts with requires expressions to check for required types and operations. The concept uses std::same_as for type constraints.
