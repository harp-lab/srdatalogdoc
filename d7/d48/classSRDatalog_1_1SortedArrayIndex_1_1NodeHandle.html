template<Semiring SR, ColumnElementTuple AttrTuple, typename ValueType = uint32_t, typename RowIdType = uint32_t>
class SRDatalog::SortedArrayIndex< SR, AttrTuple, ValueType, RowIdType >::NodeHandle

Virtual Cursor for the Sorted Array.

Does not point to a physical node object. Instead, represents a range [begin, end) within the materialized sorted columns at a specific depth.

auto SRDatalog::SortedArrayIndex< SR, AttrTuple, ValueType, RowIdType >::NodeHandle::values
inline

Returns a view of unique values for this range.

For SortedArrayIndex, this deduplicates consecutive duplicate values. Since the array is sorted, duplicates are contiguous, so this efficiently skips to the next unique value. This ensures joins iterate over unique values only, matching the behavior of HashTrieIndex.

Returns
A range view containing only unique values
