Detailed Description

template<tmp::CTuple HeadClauses>
struct SRDatalog::CompileHeadsToMIR< HeadClauses >

Compiles the rule head into MIR DestinationRelation operations.

Converts each head clause into a DestinationRelation operation that writes facts to the corresponding relation. The version is extracted from each clause (typically NEW_VER for semi-naive evaluation).

HeadClausesA std::tuple of normal clause types
