Detailed Description

Pipeline executor - core template metaprogramming interpreter for pipelines.

This file implements the PipelineExecutor, which executes pipeline operations (ColumnJoin, LetClause, DestinationRelation) using tuple-based state management. It uses precompiled hana::maps from the Pipeline for variable and iterator position lookups. This is separate from fixpoint-level operations (BuildIndex, ClearRelation, etc.) which have different execution semantics.
