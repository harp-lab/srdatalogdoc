Detailed Description

template<AST::CFixpoint FP>
struct SRDatalog::GPU::GPUQueryExecutor< FP >

Executor for running fixpoint queries on GPU.

Handles the lifecycle of a GPU query execution:

  1. prepare: Copies data from Host DB to Device DB.
  2. execute_kernel: Runs the fixpoint iteration loop on GPU.
  3. reflect: Copies results back from Device DB to Host DB.

FPThe fixpoint query type (AST::Fixpoint)
