3 /**
4  * @file store.h
5  * @brief State management stores for GPU pipeline execution
6  *
7  * @details Provides VarStore, HandleStore, and ProvStore for managing
8  * runtime state during GPU join execution.
9  *
10  * @note Compared to the CPU runtime, the GPU version uses a simplified state
11  * management strategy. Variables are stored in fixed-size arrays within
12  * wrapped structs (e.g., VarStore, HandleStore) rather than using std::tuple.
13  * This simplifies indexing in GPU kernels but may not allow the compiler to
14  * perform register allocation as effectively as it would for individual
15  * stack variables or tuple fields. On PTX seems compiler inlines it well now,
16  * but need be careful about future behavior.
17  */
