Detailed Description

template<tmp::CTuple MIROps, typename VarPosMap, typename IteratorPosMap>
struct SRDatalog::mir::Pipeline< MIROps, VarPosMap, IteratorPosMap >

Abstract Data Type (ADT) for a Pipeline of MIR operations.

Represents a sequence of MIR operations compiled from a single rule. A Pipeline encapsulates all the operations needed to execute one rule, including joins, let clauses, and destination relations. Also stores compile-time maps from variable types to stack positions and from IndexSpecT types to iterator positions.

Template Parameters
MIROpsA std::tuple of MIR operation types (ColumnSource, ColumnJoin, DestinationRelation, etc.)
VarPosMapA compile-time hana::map mapping variable types to positions
IteratorPosMapA compile-time hana::map mapping IndexSpecT types to iterator positions
