Detailed Description

template<typename Clause, CVar VarToBind, tmp::CTuple BoundVars, tmp::CTuple JoinPlan>
struct SRDatalog::ClauseToColumnSource_impl< Clause, VarToBind, BoundVars, JoinPlan >

Converts a normal clause to a ColumnSource MIR operation.

Analyzes a clause in the context of bound variables and join plan to determine how it should be accessed. Produces a ColumnSource that specifies which index to use and which variables are already bound (prefix).

Template Parameters
ClauseThe normal clause to convert
VarToBindThe variable currently being bound (for context)
BoundVarsA std::tuple of variables already bound
JoinPlanThe global join plan (variable order)
