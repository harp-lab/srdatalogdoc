Detailed Description

template<tmp::CTuple BodyClauses, tmp::CTuple GlobalJoinPlan, tmp::CTuple Indices>
struct SRDatalog::CompileBodiesToMIR< BodyClauses, GlobalJoinPlan, Indices >

Compiles the rule body into MIR operations.

Processes the rule body clauses according to the join plan, generating ColumnSource and ColumnJoin operations for normal clauses and preserving LetClause operations. Uses a fold over the join plan variables to accumulate operations in the correct order.

Template Parameters
BodyClausesA std::tuple of clause types (normal and let)
GlobalJoinPlanA std::tuple of Var types specifying join order
IndicesThe computed IndexSpecs (for reference, currently unused)
Note
The Indices parameter is kept for future use in index selection optimization.
