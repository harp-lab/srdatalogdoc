◆ compute_delta()

template<CRelationSchema Schema, AST::CSemiNaiveDatabase DB>
std::size_t SRDatalog::compute_delta ( DB & db)

Compute delta for a single relation in semi-naive evaluation.

This function performs the delta computation step for a single relation schema. It:

  1. Swaps delta and newt (newt becomes the new delta)
  2. Clears newt for the next iteration
  3. Concatenates delta into full relation
  4. Ensures canonical indexes are built

This is used during fixpoint computation to merge newly derived facts into the full relation and prepare for the next iteration.

Template Parameters
SchemaThe relation schema to compute delta for
DBThe semi-naive database type
Parameters
dbThe runtime database
Returns
The number of facts in the delta relation (before swap)

bool SRDatalog::compute_delta_for_ruleset ( DB & db)

Compute delta for all relations in a ruleset.

This function computes delta for all relations that appear in the head of rules in a ruleset. It iterates over all schemas in the RelationList and calls compute_delta for each.

Returns true if any relation had new facts (delta > 0), which is used to determine if fixpoint has been reached.

◆ execute_rules_for_fixpoint()

template<CFixpoint FP, AST::CSemiNaiveDatabase DB>
void SRDatalog::execute_rules_for_fixpoint ( DB & db)

Execute rules for a fixpoint computation.

This function executes recursive rules until a fixpoint is reached. It uses semi-naive evaluation to avoid redundant computation by only processing newly derived facts in each iteration.

The execution process:

  1. Extracts rules and incremental relations from the fixpoint
  2. Iteratively executes all rules
  3. After each iteration, computes delta (merges newt into full)
  4. Stops when no new facts are derived (delta == 0)
Template Parameters
FPA CFixpoint type containing the recursive rules
DBThe semi-naive database type

template<CNonIterativeRuleSets Rules, AST::CSemiNaiveDatabase DB>
void SRDatalog::execute_rules_for_non_iterative_rule_sets ( DB & db)

Execute rules for non-iterative rule sets.

This function executes a set of non-recursive rules exactly once. Unlike fixpoint rules, these rules are evaluated only once and do not iterate until convergence.

The execution process:

  1. Compiles each rule to MIR and executes it
  2. Extracts incremental relations from rule heads
  3. Computes delta for all incremental relations (merges newt into full)
