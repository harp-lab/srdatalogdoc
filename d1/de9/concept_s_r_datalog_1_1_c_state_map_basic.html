Detailed Description

Simplified concept that checks basic StateMap operations.

This concept checks that StateMap is a Hana map-like structure without requiring a specific variable type. Useful for generic code that doesn't need to test with a specific Var.

The concept verifies that StateMap supports the essential map operations:

  • Key iteration via hana::keys(state)
  • Size query via hana::length(state)

StateMapThe type to check (should be hana::map or compatible)
