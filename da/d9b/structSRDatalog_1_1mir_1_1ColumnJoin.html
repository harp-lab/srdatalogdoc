Detailed Description

template<CVar Var, tmp::CTuple Sources, typename Strategy = DefaultJoinStrategy>
struct SRDatalog::mir::ColumnJoin< Var, Sources, Strategy >

Abstract Data Type (ADT) for a column join operation in MIR.

Represents a multi-way join operation that binds a variable. The execution strategy is determined by the Strategy template parameter.

Template Parameters
VarThe variable to bind through this join
SourcesA std::tuple of ColumnSource types to intersect
StrategyThe join strategy to use (default: DefaultJoinStrategy)
