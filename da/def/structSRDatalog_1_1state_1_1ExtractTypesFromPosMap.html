Detailed Description

template<typename PosMap, std::size_t Size>
struct SRDatalog::state::ExtractTypesFromPosMap< PosMap, Size >

Extracts types from a position map in position order (0, 1, 2, ...).

Iterates through positions 0 to N-1 and finds the type that maps to each position. This ensures the order matches exactly what's in the map. Works with any compile-time hana::map that maps types to positions.

Template Parameters
PosMapCompile-time hana::map mapping types to positions
SizeThe number of entries in the map
