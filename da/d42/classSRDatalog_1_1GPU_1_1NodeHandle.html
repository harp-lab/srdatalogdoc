Detailed Description

template<Semiring SR, typename ValueTypeParam = uint32_t, typename RowIdType = uint32_t>
class SRDatalog::GPU::NodeHandle< SR, ValueTypeParam, RowIdType >

POD-style Handle for GPU kernel usage (fatty pointer, need slim down in future)

NodeHandle is a Plain Old Data structure containing only:

  • Device pointers (safe to copy to GPU)
  • Indices and offsets (POD types)
  • No host pointers or complex types
Template Parameters
SRThe semiring type
ValueTypeParamThe type for encoded values (default: uint32_t)
RowIdTypeThe type for row IDs (default: uint32_t)
