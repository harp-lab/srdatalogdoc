Detailed Description

template<Semiring SR, typename ValueTypeParam = uint32_t, typename RowIdType = uint32_t>
class SRDatalog::GPU::NodeHandle< SR, ValueTypeParam, RowIdType >

POD-style Cursor for GPU kernel usage (lightweight state)

NodeHandle (Cursor) contains only the mutable state needed for traversal:

  • Indices (begin, end)
  • Current depth
  • NO pointers (accessed via NodeView)

Size: 3 * 4 bytes = 12 bytes (vs 56 bytes previously)
