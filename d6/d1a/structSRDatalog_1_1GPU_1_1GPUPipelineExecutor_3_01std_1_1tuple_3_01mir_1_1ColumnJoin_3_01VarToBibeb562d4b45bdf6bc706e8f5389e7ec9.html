Detailed Description

template<typename VarToBind, typename... Sources, typename... TailOps, typename VarPosMap, typename IteratorPosMap, typename RelationPosMap, int GroupSize, bool IsLeafLevel>
struct SRDatalog::GPU::GPUPipelineExecutor< std::tuple< mir::ColumnJoin< VarToBind, std::tuple< Sources... > >, TailOps... >, VarPosMap, IteratorPosMap, RelationPosMap, GroupSize, IsLeafLevel >

Specialization for ColumnJoin: Bind variable by intersection or iterating single source.

Handles two cases:

  1. Intersection: Multiple sources (Relations) constrain the same variable. Performs a multi-way intersection of indices.
  2. Single Source: Only one relation constrains the variable. Iterates over the relation's values.

Supports subgroup primitive distribution for load balancing.
