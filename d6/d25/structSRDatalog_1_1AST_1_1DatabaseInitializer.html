Detailed Description

template<typename SrcDB, typename DstDB>
struct SRDatalog::AST::DatabaseInitializer< SrcDB, DstDB >

Initialize a destination database from a source database.

Iterates over all relations in full, delta, and newt versions and initializes the destination relation from the source relation. This relies on the destination relation type having a static to_device method (or compatible API) if it's a device relation, or copy constructor/assignment.

TODO: Standardize the initialization API (e.g. from() or copy_from()). Currently we use to_device for Host->Device.
