Detailed Description

template<CRelationSchema Schema, typename CanonicalIndexSpecs>
struct SRDatalog::FindCanonicalIndexForSchema< Schema, CanonicalIndexSpecs >

Helper to find canonical index spec for a schema in CanonicalIndexSpecs tuple.

Searches the CanonicalIndexSpecs tuple for an IndexSpecT matching the given Schema. Returns the found index spec, or creates a canonical one if not found.
