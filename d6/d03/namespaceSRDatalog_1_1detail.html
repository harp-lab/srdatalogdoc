Detailed Description

Helper to transform a tuple of types into a tuple of Column types.

Concept requiring all elements of a tuple to satisfy ColumnElement.

Uses boost::mp11 template metaprogramming to transform each type in the tuple to its corresponding Column type.

Template Parameters
AttrTupleThe tuple of attribute types to transform

This concept checks that every type in the tuple satisfies the ColumnElement concept, enabling tuple-based Relation templates while maintaining type safety.

Note
C++20 feature: Uses C++20 concepts with fold expressions (&& ...) to check all tuple elements at compile time. The fold expression iterates over all elements in the tuple using std::index_sequence and checks each element satisfies ColumnElement.
