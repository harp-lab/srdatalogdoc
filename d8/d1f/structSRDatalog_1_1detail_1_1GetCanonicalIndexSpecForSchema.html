Detailed Description

template<CRelationSchema Schema, typename AllIndexSpecs>
struct SRDatalog::detail::GetCanonicalIndexSpecForSchema< Schema, AllIndexSpecs >

Computes canonical index spec for a schema from AllIndexSpecs or creates canonical.

For a given schema, finds the first matching IndexSpec in AllIndexSpecs. If found, uses that IndexSpec's column_indexes_type. If not found, creates a canonical index spec (0, 1, 2, ..., arity-1).
