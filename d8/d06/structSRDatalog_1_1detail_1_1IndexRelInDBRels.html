template<typename T, typename Tuple>
struct SRDatalog::detail::IndexRelInDBRels< T, Tuple >

Helper to find the 0-based index of a relation type in a database tuple.

Locates the position of a relation type in the database schema tuple, enabling runtime access to the corresponding relation object.
