template<mir::CColumnSource Source, CSemiNaiveDatabase DB, CStateMapBasic StateMap>
struct SRDatalog::detail::GenerateIterator< Source, DB, StateMap >

Template metaprogramming helper to generate a single iterator from a ColumnSource.

Converts a compile-time ColumnSource MIR operation into a runtime iterator that can be used for join operations. This involves:

  1. Getting the runtime relation from the database
  2. Ensuring the required index exists (lazy index building)
  3. Getting the root iterator for the index
  4. Applying prefix values from the state map to get a prefixed iterator
Template Parameters
SourceThe ColumnSource MIR operation to generate an iterator for
DBThe semi-naive database type
StateMapThe runtime state as hana::map containing variable bindings
