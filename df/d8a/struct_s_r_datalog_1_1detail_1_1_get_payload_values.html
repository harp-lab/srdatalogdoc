template<tmp::CTuple Terms, typename StateMap>
struct SRDatalog::detail::GetPayloadValues< Terms, StateMap >

Hana-based helper to collect runtime values for a list of terms.

Given a compile-time tuple of Terms (Var, Const, or CppExpr) and a runtime state map, extracts the corresponding runtime values. Uses state::get_term_value for compile-time type dispatching to handle different term types elegantly.

Benefits over manual specialization:

  • Single implementation handles all term types using if constexpr
  • More extensible (easy to add new term types)
  • Cleaner and more functional style
  • Better compile-time performance
Template Parameters
TermsA std::tuple of CTerm types to extract values for
StateMapThe runtime state as hana::map containing variable bindings
