Detailed Description

template<typename T>
class SRDatalog::GPU::DeviceArray< T >

GPU device array wrapper using Umpire allocator.

Template Parameters
TElement type

Similar to std::vector but for device memory. Tracks size and capacity separately to avoid reallocation on shrink.
