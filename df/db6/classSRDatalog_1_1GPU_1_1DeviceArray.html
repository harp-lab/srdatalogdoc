Detailed Description

template<typename T>
class SRDatalog::GPU::DeviceArray< T >

GPU device array wrapper using RMM device_uvector.

Template Parameters
TElement type

Similar to std::vector but for device memory. Uses rmm::device_uvector<uint32_t> internally to store raw data, with default pooling memory resource.

Note
This class is host-only (all methods are host)
