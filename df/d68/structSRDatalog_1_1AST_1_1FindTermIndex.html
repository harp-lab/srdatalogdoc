Detailed Description

template<CTerm T, tmp::CTuple TermList>
struct SRDatalog::AST::FindTermIndex< T, TermList >

Finds the index of a term in a term list.

Template metaprogramming trait that locates a term's position in a tuple of terms. Returns -1 if the term is not found. Used during clause analysis to map variables to column positions.

Template Parameters
TThe term to find (must satisfy CTerm)
TermListA std::tuple of term types
