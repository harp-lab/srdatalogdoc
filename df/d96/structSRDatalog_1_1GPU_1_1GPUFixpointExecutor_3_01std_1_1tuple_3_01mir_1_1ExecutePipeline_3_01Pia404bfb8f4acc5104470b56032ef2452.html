Detailed Description

template<typename Pipeline, typename... TailOps, typename RelationsBundle, typename SchemaTuple>
struct SRDatalog::GPU::GPUFixpointExecutor< std::tuple< mir::ExecutePipeline< Pipeline >, TailOps... >, RelationsBundle, SchemaTuple >

Specialization for ExecutePipeline: Launches a GPU pipeline.

  1. Extracts necessary handles (Root Sources and Full Destinations).
  2. Copies handles to Device memory.
  3. Launches Count Kernel -> Scan -> Materialize Kernel sequence.
  4. Recurses to next MIR operation.
