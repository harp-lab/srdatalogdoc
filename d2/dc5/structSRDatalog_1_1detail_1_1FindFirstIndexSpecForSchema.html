struct SRDatalog::detail::FindFirstIndexSpecForSchema< Schema, AllIndexSpecs >

Helper to find the first IndexSpec matching a given schema.

Searches through AllIndexSpecs to find the first IndexSpecT whose schema_type matches the given Schema. Returns the IndexSpecT type if found, or std::tuple<> if not found.
