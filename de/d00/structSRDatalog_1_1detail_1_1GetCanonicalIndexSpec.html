template<CRelationSchema Schema, std::size_t Ver = FULL_VER>
struct SRDatalog::detail::GetCanonicalIndexSpec< Schema, Ver >

Helper to get canonical index spec for a schema.

Creates an IndexSpecT with canonical index (0, 1, 2, ..., arity-1) for the given schema.
