Detailed Description

template<typename State, typename VarToBind, tmp::CTuple AllJoinPlan, tmp::CTuple AllBodyClauses, tmp::CTuple Indices>
struct SRDatalog::ProcessOneVariable_impl< State, VarToBind, AllJoinPlan, AllBodyClauses, Indices >

Implementation of processing one variable in the join plan.

For a given variable to bind:

  1. Finds all LetClauses that bind this variable
  2. Finds all normal clauses that reference this variable
  3. Converts normal clauses to ColumnSources
  4. Creates a ColumnJoin if multiple sources exist
  5. Updates the fold state with new operations and bound variables
Template Parameters
StateThe current fold state (BoundVars, AccumulatedOps)
VarToBindThe variable currently being processed
