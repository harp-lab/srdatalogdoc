Detailed Description

template<typename T, typename CanonicalIndexSpecs>
struct SRDatalog::ReplaceDestinationRelationWithCanonicalIndex< T, CanonicalIndexSpecs >

Replaces a DestinationRelation with canonical index from CanonicalIndexSpecs.

Takes a DestinationRelation and looks up its canonical index spec from the CanonicalIndexSpecs tuple, then creates a new DestinationRelation with the canonical index. The version is preserved from the original DestinationRelation.

Template Parameters
DestRelThe DestinationRelation to replace
CanonicalIndexSpecsA std::tuple of IndexSpecT types (from CollectCanonicalIndexSpecs)
