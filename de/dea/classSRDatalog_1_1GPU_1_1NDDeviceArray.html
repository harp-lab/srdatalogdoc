Detailed Description

template<typename T, std::size_t N>
class SRDatalog::GPU::NDDeviceArray< T, N >

N-dimensional device array with flat column-major storage.

Memory layout: [col0: 0..stride][col1: 0..stride]...[colN-1: 0..stride]

Where stride >= num_rows. This allows resize() to shrink without reallocating or moving data.
