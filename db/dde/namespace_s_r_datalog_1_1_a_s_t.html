template<CDatabase DB>
auto SRDatalog::AST::init_database ( memory_resource * resource)

Initializes a database with a custom memory resource.

Convenience function that creates all relations in a database schema using the provided memory resource. This is used to create runtime database instances with custom memory management.

Template Parameters
DBThe Database ADT type (must satisfy CDatabase)
Parameters
resourceThe memory resource to use for all relations
Returns
A tuple of Relation objects initialized with the memory resource
