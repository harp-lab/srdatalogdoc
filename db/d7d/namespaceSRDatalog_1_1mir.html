Detailed Description

Mid-level Intermediate Representation (MIR) namespace.

Contains the MIR AST structures used for column-oriented join execution. MIR is generated from the high-level AST during compilation and is closer to the actual execution model.

Abstract Data Type (ADT) for a destination relation in MIR.

Represents an operation that writes a fact to a relation. This is generated from rule heads during compilation. The terms specify what values to write, which may include variables bound earlier in the join plan. The IndexSpec specifies which index to use for deduplication checks.

Template Parameters
SchemaThe relation schema to write to
TermsA std::tuple of CTerm types specifying the values to write
VerThe version number (typically NEW_VER) for semi-naive evaluation
IndexSpecThe IndexSpecT type specifying which index to use (defaults to empty index as placeholder)

Abstract Data Type (ADT) for an aggregation operation in MIR.

Represents an operation that aggregates values from a relation cursor. The cursor is restricted by prefix variables. The aggregation function is applied to the values in the cursor's range to produce a single result, which is bound to VarToBind.

Template Parameters
VarToBindThe variable to bind with the aggregation result
IndexThe IndexSpec specifying which index to use
PrefixVarsVariables that are already bound (prefix)
AggFuncThe aggregation functor type

Abstract Data Type (ADT) for a column join operation in MIR.

Represents a multi-way join operation that binds a variable by intersecting multiple column sources. This implements Worst-Case Optimal Join (WCOJ) algorithms using hash intersection. The version is extracted from the ColumnSources (they should all have the same version).

Template Parameters
VarThe variable to bind through this join
SourcesA std::tuple of ColumnSource types to intersect
