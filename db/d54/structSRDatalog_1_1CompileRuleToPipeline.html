Detailed Description

template<CRule Rule>
struct SRDatalog::CompileRuleToPipeline< Rule >

Compiles a Rule to a Pipeline.

Wraps the MIR operations from a rule into a Pipeline ADT. This provides a higher-level abstraction for rule execution. Also computes and stores both the variable-to-position map (based on join plan) and the IndexSpecT-to-iterator-position map (based on ColumnSource operations).
