template<CRule rule>
struct SRDatalog::ComputeNaiveIndices< rule >

Computes the set of required IndexSpec ADTs for a rule.

Analyzes a rule and determines all indexes needed to execute it efficiently. Uses the join plan specified in the rule to determine optimal index access patterns. The result is deduplicated to avoid redundant indexes.

Template Parameters
ruleThe rule to analyze (must satisfy CRule)
Note
Currently uses the naive (first-appearance) variable order from the join plan. Future versions may support more sophisticated join ordering.
