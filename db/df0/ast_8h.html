Detailed Description

Abstract Syntax Tree (AST) for Datalog using Template Metaprogramming.

This file defines the compile-time AST structures for representing Datalog programs in C++. The AST uses template metaprogramming to encode programs as types, enabling:

  • Type-safe program representation
  • Compile-time analysis and transformation
  • Zero-overhead runtime execution
  • Integration with C++ type system

The AST includes:

  • Basic constructs: Var, Const, CppExpr, Clause
  • Rule structures: Rule, Fixpoint, NonIterativeRuleSets
  • Program structure: Program, Database
  • MIR (Mid-level IR): ColumnSource, ColumnJoin, DestinationRelation
  • Template metaprogramming utilities for AST analysis

All AST nodes are compile-time types, not runtime values. The actual execution happens in runtime.h which interprets MIR operations.
